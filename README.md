# PIRUS Regression Project
This repository stores all of the files related to a logistic regression model I trained using the Profiles of Individual Radicalization in the United States (PIRUS) from the University of Maryland's National Consortium for the Study of Terrorism and Responses to Terrorism (START). I want to thank the University of Maryland and the people at START for making this fascinating data available to the public.

# Project Details
The goal of this project is to use the PIRUS dataset to train a logistic regression model predicting whether or not a Right-Wing, Left-Wing, or Single-Issue Extremist will engage in or plot a violent act.

Citation:
National Consortium for the Study of Terrorism and Responses to Terrorism (START). (2023). Profiles of Individual Radicalization in the United States [Data file]. Retrieved from (http://www.start.umd.edu/pirus)
