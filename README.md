# PIRUS Regression Project
This repository stores all of the files related to a series of logistic regression models I trained using the Profiles of Individual Radicalization in the United States (PIRUS) from the University of Maryland's National Consortium for the Study of Terrorism and Responses to Terrorism (START). I want to thank the University of Maryland and the people at START for making this fascinating data available to the public and for making this project possible. I am thrilled to be able to be working on this and hope to do more with the PIRUS dataset in the future.

# Project Details
The goal of this project is to use the PIRUS dataset to train a logistic regression model predicting whether or not a Right-Wing, Left-Wing, or Single-Issue Extremist will participate in or commit an act of political violence.
